# docprims v0.1.5

**Release Date:** 2026-07-07
**Status:** Patch Release (runtime floors + repository guidance)

## Summary

This release refreshes package runtime floors and repository guidance after the v0.1.4 publishing fixes. It keeps the TypeScript 6.x and napi-rs 3.x upgrade out of scope for the later coordinated modernization pass.

## Highlights

- **Rust MSRV**: Raised the workspace minimum supported Rust version to 1.88.0.
- **TypeScript Node floor**: `@3leaps/docprims` now requires Node.js 22 or newer.
- **npm trusted publishing hardening**: Publish workflow checks Node >=22.14.0 and npm >=11.5.1 before publishing.
- **TypeScript workflow alignment**: Binding tests, release validation, and N-API prebuilds now validate on Node 22.
- **Repository guidance cleanup**: Agent guidance, local-only planning conventions, and YAML linting configuration were refreshed.

## Runtime Floors

| Component | Floor |
|-----------|-------|
| Rust workspace | 1.88.0 |
| TypeScript package | Node.js 22+ |
| TypeScript CI/prebuild validation | Node.js 22 |
| npm trusted publishing | Node.js >=22.14.0 and npm >=11.5.1 |

## TypeScript Package Changes

The TypeScript package metadata now declares:

```json
{
  "engines": {
    "node": ">=22"
  }
}
```

Platform optional dependencies were advanced to the v0.1.5 package set:

| Platform | Package |
|----------|---------|
| Linux x64 (glibc) | `@3leaps/docprims-linux-x64-gnu` |
| Linux x64 (musl) | `@3leaps/docprims-linux-x64-musl` |
| Linux arm64 (glibc) | `@3leaps/docprims-linux-arm64-gnu` |
| Linux arm64 (musl) | `@3leaps/docprims-linux-arm64-musl` |
| macOS arm64 | `@3leaps/docprims-darwin-arm64` |
| Windows x64 | `@3leaps/docprims-win32-x64-msvc` |

## Trusted Publishing Guard

The npm publish workflow runs on Node 24 but explicitly enforces the trusted-publishing minimums before publishing:

- Node.js >=22.14.0
- npm >=11.5.1

The same static guard runs locally through:

```bash
make npm-publish-prereqs-check
```

It is also wired into `make lint`, so the normal quality gate catches workflow drift.

## Repository Guidance

v0.1.5 refreshes public repository guidance:

- Planning artifacts are local-only and non-canonical.
- `docs/orientation/sources-of-truth.md` remains the canonical guide for source-of-truth boundaries.
- YAML linting is configured explicitly at repo root.
- Commit attribution guidance uses bare role slugs.

## Installation Notes

### CLI from a checkout

```bash
cargo install --path crates/docprims-cli
```

### TypeScript from a checkout

```bash
cd bindings/typescript/docprims
npm install
npm run build
npm run build:native
```
